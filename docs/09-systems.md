> **이 문서의 목적은 하나입니다 — "이미 있는 걸 없다고 말하는 사고"를 막는 것.**
>
> 세션 시작 훅(`.claude/hooks/session-start.sh`)이 이 파일을 컨텍스트에 자동으로 넣습니다.

## 2. 아직 **없는** 것

이쪽도 확인 없이 "있다"고 말하지 않기 위해 적어둡니다.

| 없는 것 | 비고 |
|---|---|
| **파티 시스템** | 파티 등급 · 동행 연차 · 가입 자격. `CombatantFactory.FormParty`는 전투용 조립일 뿐 |
| **성격/시너지** | `Temperament` 3종은 *성장* 성향이고, 파티 오라와는 별개 |
| **지시 불통 상태이상** | 공황 · 혼란 · 광폭 · 기절 없음. `Taunted`가 대상만 강제 |
| **전투 이탈(후퇴)** | `MoveBack`은 후열 이동일 뿐, 전투를 그만두는 행동이 없음 |
| **개별 장비 아이템** | 스타일+무기종 조합만 있고 아이템 인스턴스는 없음 |
| **경제 구조** | 수입은 정수 반환뿐. 자금·유지비·보수 분배 타입 없음 |
| **직렬화/세이브** | JSON·저장·불러오기 전혀 없음 |
| **액티브/패시브 스킬** | 숙련도로 배우는 스킬 목록 없음 (`SupportSkill`은 별개 축) |
| **연 단위 달력 UI** | 훈련/의뢰/휴식 3지선다 월별 편성 없음 |
| 게임 엔진 | 의도된 부재 — ADR 0001 |

## 3. 제약이 기능을 막고 있는 곳

기능은 있는데 설정 때문에 못 쓰는 자리. **"없다"고 결론내기 전에 여기를 봅니다.**

| 자리 | 현재 | 문제 |
|---|---|---|
| `CommandRules.BasePoints = 3` | 전투당 개입 3점, 위치 변경 2점 | 전투가 3~4라운드라 사실상 1~2번. 주인님 결정: **횟수 제한 폐지** |
| 1인 파티 전투 | 튜토리얼이 솔로 | 전열/후열이 죽은 기능이 됨 |
| `MaxEvasionChance = 0.28` | 회피 상한 28% | 격차 900 → 99% 설계와 아직 안 맞음 (미구현) |
| 능력치 스케일 | 하드캡 999 결정됐으나 공식은 구 스케일 | `docs/08-design-revision.md` 참조 |
