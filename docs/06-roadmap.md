# 06. 로드맵

출시까지의 길을 여섯 마일스톤으로 나눈 계획이다. 마일스톤마다 산출물과 종료 판단
기준을 정해 두고, 하나가 끝날 때마다 계속할지를 결정한다.

작성 2026-07 · 상태 초안

## 원칙

1. **불확실한 것부터 먼저 만든다.** "이게 재미있는가"는 가장 불확실하고 가장 비싼 질문이다.
   확실한 것(UI 다듬기, 콘텐츠 양)은 뒤로 미룬다.
2. **각 마일스톤은 판단 지점이다.** 끝날 때마다 계속할지 결정한다.
3. **Steam 페이지를 최대한 일찍 연다.** 위시리스트 적립 기간이 곧 경쟁력이다.
4. **일정은 계획의 1.5~2배가 걸린다고 전제한다.** 여기 적힌 기간은 이미 그 보정을 반영한 것이 아니다.

---

## M1 — 코어 프로토타입 (재미 검증)

**기간 목표:** 6~10주 · **산출물:** 콘솔에서 텍스트로 플레이 가능한 육성 런 + 전투

엔진 없음. 순수 C#만.

- [x] 결정론적 RNG (`IRandomSource`, 시드 기반 재현)
- [x] 모험가 데이터 모델 (스탯 · 특성 · 이력)
- [x] **달 단위 달력** (매달 훈련/의뢰/휴식/전직, 의뢰 기간만큼 칸 잠금)
- [x] 전투 해석기 (턴 진행, 전술 규칙 평가, 데미지 계산, 전열/후열)
- [x] Utility AI + 판단력 스탯 연동
- [x] 전투 중 개입 (횟수 제한 없음)
- [x] 콘솔 UI (텍스트로 전부 플레이 가능 · Docker로도 실행)
- [x] 배치 시뮬레이터 (`-- sim` 로 승률 분포 출력)
- [x] 의뢰 형태 4종 · 파티 2층 · 등급 F~SS · 승급 의뢰 · 무기 4칸 · 직업/스킬 표 · 상태 효과 기전 8종

**남은 것**은 [05-gaps.md](05-gaps.md)의 "아직 없는 것"에 있다.
큰 것은 이해도 · 자동 방침 · 호위 대상 개체 · 경제 구조 이관이다.

**M1 종료 판단 (헌장의 중단 조건):**
- 텍스트만으로도 "한 번 더" 돌리고 싶은가?
- 육성 런이 최적해를 외우면 끝나는 퍼즐이 되지 않았는가?
- 판단력 스탯 차이가 전투에서 체감되는가?

> **하나라도 아니면 여기서 설계를 고친다.** 그림을 붙인다고 재미없는 게 재미있어지지 않는다.

## M2 — 엔진 선택 + 플레이 가능한 세로 슬라이스

**기간 목표:** 8~12주 · **산출물:** 화면이 있는, 처음부터 끝까지 도는 육성 런 1회

- [ ] Unity / Godot 각각에 얇은 뷰를 붙여 2주 비교 → **엔진 확정** ([ADR 0001](adr/0001-engine-agnostic-core.md))
- [ ] 레이어 조합형 초상화 시스템 (임시 파츠로)
- [ ] 육성 런 UI
- [ ] 전투 화면 (배속 · 스킵 포함)
- [ ] 세이브/로드
- [ ] 사운드 1차 (Sonniss 번들)

## M3 — 길드 층 + 게임의 형태

**기간 목표:** 10~14주

- [ ] 길드 재정 · 평판 · 시설
- [ ] 절차적 의뢰 생성
- [ ] 모험가 영입 · 은퇴 · 사망 순환
- [ ] 이력(Chronicle) 시스템
- [ ] 절차적 이벤트
- [ ] 첫 외부 플레이테스트 (5~10명)

---

## M4 — 데모 + Steam 페이지 ★ 가장 중요한 마일스톤

**기간 목표:** 8~12주 · **목표 시점: 2027년 중반**

- [ ] 초상화 파츠 세트 확보 (외주/구매, 10~15만원)
- [ ] **Steam 캡슐 이미지 외주** (25~35만원) ← 단일 최고 레버리지
- [ ] Steam Direct 등록 ($100) + 스토어 페이지 공개
- [ ] 트레일러 자체 제작 (첫 3초에 훅)
- [ ] 데모 빌드 (= 육성 런 1회 + 전투 몇 회)
- [ ] 마케팅 시작 — devlog, 개발 과정 공유

> **위시리스트 적립 기간이 성패를 가른다.** Next Fest 참가는 위시리스트가
> 최소 2,000 이상 쌓인 뒤에 해야 의미가 있다. 그 미만으로 들어가면 평균 300개
> 획득에 그친다.

**M4 종료 판단:** 페이지 공개 후 3개월간 위시리스트 1,000 미달 시
컨셉 또는 프레젠테이션을 근본적으로 재검토.
