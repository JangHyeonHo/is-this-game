## 1. 컨셉

> **판타지 길드를 운영하며 모험가를 한 명씩 짧게 육성하고,
> 그들로 파티를 짜서 의뢰에 내보내는 게임.**

**한 줄 훅:** 모험가는 스스로 싸운다. 당신이 키운 만큼만.

**장르 태그:** Management, Party-Based RPG, Roguelite, Auto Battler, Character Training

**비교 대상 (플레이어에게 설명할 때):**
"우마무스메의 육성 사이클 + Battle Brothers의 용병단 운영 + 파이널 판타지 12의 감빗"

## 2. 3층 루프 구조

```
┌─ 길드 층 (수십 시간, 세이브 단위) ──────────────────────┐
│  재정 · 평판 · 시설 · 경쟁 길드 · 시즌 진행              │
│                                                          │
│  ┌─ 모험가 층 (30~40분, 반복 단위) ─────────────────┐   │
│  │  영입 → 육성 런 → 은퇴/사망                       │   │
│  │                                                    │   │
│  │  ┌─ 전투 층 (2~5분) ──────────────────────────┐   │   │
│  │  │  파티 편성 → 자동 전투 + 개입 (횟수 제한 없음) │   │   │
│  │  └─────────────────────────────────────────────┘   │   │
│  └────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────┘
```

**각 층이 존재하는 이유:**

| 층 | 플레이어에게 주는 것 | 개발 관점의 이유 |
|---|---|---|
| 전투 | 즉각적 피드백, "내 빌드가 통했다" | 자동 기반이라 조작 UI·애니메이션 요구가 낮음 |

> 개입 횟수 제한(지휘 포인트)은 **폐기**됐습니다 — 아끼게 만들면 결국 안 쓰게 되고,
> 그게 "개입으로 할 게 없다"의 원인이었습니다. 유일한 제약은 공포·혼란(지시 불통)입니다.
| 모험가 | 애착, 반복 가능한 세션, 실험 | **루프 하나만 잘 만들면 콘텐츠로 불릴 수 있음.** 데모 = 육성 런 1회 |
| 길드 | 장기 목표, 러닝타임 | 콘텐츠 재사용으로 플레이 시간 확보. 환불률 방어 |

## 3. 모험가

### 3.1 표현 방식 — 레이어 조합형 초상화

Battle Brothers 방식. 파츠를 레이어로 겹쳐 조합합니다.

```
[배경] → [체형] → [피부/종족] → [얼굴] → [머리] → [수염] → [흉터] → [장비] → [상태 오버레이]
```

**설계 원칙: 아트가 곧 시뮬레이션 상태의 표현이 된다.**

- 부상을 입으면 흉터 레이어가 **영구히** 붙는다
- 나이를 먹으면 머리색이 변한다
- 장비를 바꾸면 초상화에 반영된다
- 사기·부상 상태가 오버레이로 드러난다

파츠 세트 한 벌(예산 10~15만원)로 수천 명의 고유한 모험가를 생성할 수 있고,
**추가 아트 비용 없이 캐릭터가 "변화"합니다.**

### 3.2 애착은 그림이 아니라 기억에서 나온다

이 게임의 핵심 가설입니다. 검증된 선례가 있습니다.

| 게임 | 아트 수준 | 애착의 근원 |
|---|---|---|
| RimWorld | 졸라맨 | 관계 · 트라우마 · 과거사 |
| Dwarf Fortress | ASCII | 생성된 역사 |
| Battle Brothers | 레이어 조합 초상화 | 출신 · 생존한 전투 · 부상 이력 |

따라서 **모든 모험가는 이력(Chronicle)을 누적**합니다.

```
아스카르 (37세, 몰락 귀족 출신)
  · 첫 의뢰에서 동료 미렌을 잃음        → [죄책감] 특성 획득
  · 늑대굴 소탕 3회 성공                → [야수 사냥꾼] 특성
  · 왼팔 부상 (영구)                    → 근력 -15, 흉터 레이어
  · 신입 3명을 훈련시킴                 → [멘토] 특성
  · 은퇴: 42세, 길드 훈련교관으로 전직  → 이후 신입 육성에 보너스
```

은퇴한 모험가가 사라지지 않고 길드에 남는 것이 중요합니다.
**손실이 자산으로 전환되면 애착이 시스템적으로 보상됩니다.**

### 3.3 능력치 — 원천 6 + 파생

**훈련으로 직접 올리는 것은 원천 여섯 개뿐입니다.**

| 원천 | 좌우하는 것 |
|---|---|
| **힘** | 물리 위력, 운반 |
| **민첩** | 행동 속도, **회피** |
| **기교** | **치명타**, 함정 해제, 채집 |
| **활력** | 최대 HP, 물리 방어 |
| **지능** | 마법 위력, 감정, 함정 감지 |
| **정신** | 최대 마나, 마법 방어 |

전투용 수치를 직접 훈련하지 않는 이유는 두 가지입니다.
하나를 올렸을 때 **여러 곳이 움직여야 육성 선택이 무거워지고**,
전투 밖의 것(운반·함정 해제·감정)과 **연결할 고리**가 필요하기 때문입니다.

> 예전에는 공/방/마공/마방/속도를 직접 훈련했는데, 그러면 "채집이 공격력에 의존"처럼
> 억지 매핑이 생깁니다. 곡괭이질을 공격력으로 하는 건 말이 안 됩니다.

**파생 수치는 화면에 항상 같이 보여줍니다.** 자동 전투 게임에서 플레이어는 숫자를 보고
편성을 판단하는데, "지능 62"만 보여주면 이 아이가 얼마나 센지 알 수 없습니다.

```
아스카르 · 견습 마법사 (17세)

  힘   24        물리 위력  31        최대 HP   142
  민첩 38        마법 위력  71        최대 MP    58
  기교 31        물리 방어  20        행동속도   45
  활력 45        마법 방어  32        치명타율    6%
  지능 66                             회피율      5%
  정신 51                             판단력     34
```

#### ★ 파생도 직접 오릅니다

```
파생 수치 = f(원천 능력치) + 보정치
                ↑ 훈련으로      ↑ 실전에서 겪은 것으로
```

계속 맞다 보면 몸이 단단해지고, 급소를 노리다 보면 손에 익습니다.
**원천 능력치가 같아도 이력이 다르면 실제로 다른 캐릭터**가 됩니다.

| 겪은 것 | 붙는 보정 |
|---|---|
| 물리 피해를 받음 | 물리 방어, 최대 HP |
| 마법 피해를 받음 | 마법 방어 |
| 치명타를 냄 | 치명타율 |
| 공격을 피함 | 회피율 |
| 위치를 자주 바꿈 | 행동 속도 |

**보정에는 상한이 있습니다** (치명타율 +12%p 등). 보정만으로 캐릭터가 완성되면
원천 능력치를 키울 이유가 사라지기 때문입니다.

실측 — 전열에서 5년 굴린 탱커: `최대 HP +10, 물리 방어 +4`.

#### 특화는 잠재력에서 나옵니다

능력치마다 잠재력 상한이 따로 굴려지므로, **캐릭터는 자연스럽게 특화됩니다.**
지능과 정신만 높은 아이는 마법사로, 힘과 민첩이 높은 아이는 유격수로 쓰게 됩니다.
직업을 고르는 게 아니라 **타고난 것을 발견하는** 구조입니다.

여기에 더해 이 게임의 중심 스탯이 하나 더 있습니다.

| **판단력 (Judgement)** |
|---|
| 전투 중 AI가 얼마나 좋은 선택을 하는지. 그리고 실전에서 얼마나 잘 살아남는지 |

판단력은 **훈련보다 실전에서 훨씬 빠르게 오릅니다.** 죽을 위험을 감수해야 얻어지는
스탯이라는 점이 "언제 내보낼 것인가"라는 질문에 무게를 더합니다.
판단력이 전투에서 어떻게 작동하는지는 4장에서 설명합니다.

### 3.4 성장 타입 — 이 게임의 중심 도박

모든 모험가는 영입 시점에 **숨겨진 성장 곡선**을 갖습니다.

| 요소 | 내용 |
|---|---|
| **개화 시기 (Peak Age)** | 조숙형 17~19세 / 보통 20~23세 / **대기만성형 24~27세** |
| **개화 폭** | 좁으면 짧고 강하게, 넓으면 완만하게 오래 자람 |
| **기질 (Temperament)** | 수련형(훈련에서 잘 배움) / 균형형 / **실전형(실전에서 훨씬 빨리 배움)** |
| **잠재력** | 능력치별 상한. 훈련으로도 넘지 못함 |
| **노화 시작 나이** | 이후 매년 능력치가 깎임 |

개화기에서 멀어도 성장이 완전히 멈추지는 않습니다(최소 22% 배율).
이 하한이 없으면 대기만성형을 데리고 있을 이유가 사라지기 때문입니다.
**개화 시기는 "성장 배율"이지 "성장 가능 여부"가 아닙니다.**

#### ★ 정보 비대칭 — 운을 판단으로 바꾸는 장치

성장 타입은 플레이어에게 **직접 보이지 않습니다.** 하지만 완전히 숨기면 안 됩니다.

> 완전히 숨기면 매년의 선택이 **판단이 아니라 그냥 주사위**가 됩니다.
> 완전히 공개하면 **도박이 사라집니다.**

그래서 **틀릴 수 있는 힌트**를 줍니다.

```
[스카우트 리포트]  확신도: 짐작뿐 (18%)
  · 늦게 피는 편으로 보인다
  · 실전에서 배우는 타입
  · 추정 잠재력: 힘49 민44 기52 활58 지83 정71
```

**확신도는 이렇게 오릅니다:**
- 함께 보낸 연차 (관찰) — 기여가 점점 둔화됨. 5년쯤이면 웬만큼 알게 됨
- 길드의 감정 시설 투자
- **멘토** — 실전을 오래 살아남은 선배일수록 사람 보는 눈이 좋음

확신도가 낮으면 힌트가 **실제로 틀립니다** (신입·시설 없음 기준 개화 시기 적중률 약 36%).
"확신도 18%"라는 표시 자체가 플레이어에게 의미를 가져야 하기 때문입니다.

결과적으로 **정보 자체가 자원이 되고, 길드 성장의 보상**이 됩니다.

### 3.5 무기 — ⚠️ 폐기됨 → [08](08-design-revision.md) §16.2 · §16.2b

**낡은 내용을 지웠습니다.** 여기에는 스타일 7종(한손+방패/쌍수/양손/활/석궁/지팡이/창)과
무기종 4종, 그리고 **회복·도발·광역·마법·후열타격을 무기가 결정하는 표**가 있었습니다.

지금은 이렇습니다.

- **무기는 위력·속도·사거리만 정합니다.** 회복·도발·광역·후열타격은 전부 **스킬**입니다
- **스타일이라는 개념이 없습니다.** 무기를 **주무기/보조무기 × 좌/우 4칸**에 들고,
  손 배치가 곧 스타일입니다 (오른손 검 + 왼손 방패 = 한손+방패)
- 치명타 특성은 무기가 아니라 **숙련 패시브**에서 나옵니다

#### 적성 — 랜덤이되 능력치와 상관관계

적성은 능력치 잠재력에서 파생되되 노이즈가 섞입니다.

> ⚠️ 여기에 스타일 7종의 적성 분포 실측표가 있었습니다. **스타일이라는 개념이 없어졌고**
> 측정치도 무효라 지웠습니다. 적성은 이제 **무기 종류별**로 붙습니다 (`WeaponAptitudes`).

살아 있는 것은 원칙입니다.

- **능력치가 극단적이면 무기가 사실상 정해지고, 평범하면 발견의 여지가 큽니다.**
  "지능 최고인데 대검 적성" 같은 불량품은 잘 나오지 않으면서, 애매한 아이는
  뚜껑을 열어봐야 압니다
- **노이즈가 섞입니다** — 그래서 가끔 예상 밖의 재능이 나오고, 그게 발견의 재미입니다

> **안전장치:** 모든 캐릭터는 최소 한 무기에 B 이상 적성을 보장받습니다.
> 5년 키워서 알아낸 게 "얘는 못 쓴다"면 그건 긴장이 아니라 처벌입니다.

#### 숙련도 — 랜덤이 아니라 이력

적성이 "얼마나 빨리 느는가"라면, 숙련도는 **"실제로 얼마나 익혔는가"**입니다.

- 그 무기를 들고 보낸 햇수만큼 자동으로 쌓입니다 (**훈련 +9 / 실전 +15**)
- 오르는 속도는 적성에 비례 (5년 후 적성 E는 11, S는 61)
- 전투 효율 0.75배(숙련 0) ~ 1.30배(숙련 100)
- **무기를 바꿔도 예전 숙련도는 사라지지 않습니다.** 돌아갈 수는 있되, 새 무기는 처음부터

이래서 "이 아이는 창을 10년 썼다"가 성립하고, **무기 변경에 시간이라는 기회비용**이 붙습니다.

> **월 단위 선택 축을 늘리지 않았습니다.** 숙련도는 장착한 무기로 자동 누적되므로,
> 매달의 선택은 여전히 7능력치 + 휴식이고 무기는 연 단위 결정입니다.

### 3.6 직업 — ⚠️ 폐기됨 → [08](08-design-revision.md) §16 · §6

**낡은 내용을 지웠습니다.** 여기에는 *"직업은 별도의 능력 축이 아니라 숙련도에서
파생되는 칭호"* 라는 규정과, **등급 = 숙련도 구간**(견습 0~19 → 전설 90~100) 표가 있었습니다.
그 구조에는 치명적 문제가 있었습니다 — **훈련만 5년 해도 3등급이 됩니다. 돈을 한 푼도
안 벌어온 사람이요.**

지금은 이렇습니다.

- **직업은 무기와 별개 축**입니다. 요구 숙련이 다른 표의 한 줄이고, 액티브 슬롯 수와
  수주 자격을 정합니다. 숙련 조합으로 **히든 직업**이 열립니다(활 60 + 지팡이 60 = 마궁사)
- **등급은 F~SS 여덟 단계**이고 숙련도와 무관합니다. **승급 의뢰를 통과해야** 오릅니다 —
  실전을 요구하므로 "훈련만 해서 등급을 올리는" 것이 막힙니다
- 유지비는 직업 데이터의 한 열입니다 (`Job.Upkeep`)

## 4. 전투 — 감빗 + 판단력 모델

> **전투는 자동으로 진행된다. 다만 캐릭터가 얼마나 똑똑하게 싸우는지는
> 육성으로 얻은 판단력과 플레이어가 편성한 전술 규칙이 결정한다.**

### 4.1 전술 규칙 (Tactic)

FF12 감빗과 유사한 조건-행동 규칙입니다. 위에서부터 순서대로 평가합니다.

```
1. [아군 HP < 30%]          → 회복약 사용
2. [적이 시전 중]            → 차단
3. [적 후위가 노출됨]        → 돌격
4. (기본)                    → 가장 가까운 적 공격
```

**규칙 슬롯은 육성으로 늘어나고, 규칙 자체도 육성으로 배웁니다.**
신입은 슬롯 2개에 기본 규칙만 갖고, 베테랑은 슬롯 6개에 정교한 규칙을 갖습니다.

### 4.2 판단력 = AI 품질

여기가 이 설계의 핵심입니다. **판단력 스탯이 AI의 실행 품질을 좌우합니다.**

| 판단력 | 전투 중 행동 |
|---|---|
| 낮음 | 규칙을 자주 무시한다. 위험할 때 후퇴하지 않고, 회복약을 아끼다 죽는다. 타겟 선택이 나쁘다 |
| 보통 | 규칙대로 움직인다 |
| 높음 | 규칙에 없는 상황도 스스로 잘 판단한다 (Utility AI의 가중치가 정확해짐) |

구현상으로는 **Utility AI의 점수 계산에 판단력이 개입**합니다.
판단력이 낮으면 점수에 노이즈가 끼거나 근시안적 평가(다음 1턴만 봄)를 하고,
높으면 정확하고 멀리 봅니다.

### 4.3 플레이어의 개입 — ⚠️ 지휘 포인트는 폐기됨 → [08](08-design-revision.md) §14

**낡은 내용을 지웠습니다.** 여기에는 **지휘 포인트(Command Point)** 비용표가 있었습니다
(행동 지시 1 · 타겟 지정 1 · 후퇴/대형 변경 2 · 직접 조작 2).

지금은 **횟수 제한이 없습니다.** 아끼게 만들면 결국 안 쓰게 되고, 실제 플레이 피드백
*"개입으로 할 수 있는 게 없다"* 의 원인이 그 3포인트 예산이었습니다
(3~4라운드 전투에서 대형 변경 한 번이면 예산의 2/3).

유일한 제약은 **공포·혼란에 걸린 아군에게는 지시가 통하지 않는 것**입니다.
지시도 스킬·무기·쿨다운·마나를 지켜야 합니다 — 그 검사는 코어에 있습니다.

### 4.5 포지션 — 고정된 대형이 아니라 매 순간의 선택

**전열/후열은 배치가 아니라 행동입니다.** 전투 중 언제든 이동할 수 있고, 그 판단이 곧 판단력입니다.

| 규칙 | 내용 |
|---|---|
| 근접 무기의 사거리 | 적 **전열까지만** 닿음 |
| **전열이 비면** | 후열이 그대로 노출됨 → 전열 유지 자체가 방어 행위 |
| 후열에 있으면 | 받는 피해 **0.75배** |
| 근접 무기가 후열에서 | 위력 **0.45배** (0이 아닌 이유: 완전 무력화되면 후퇴가 사망 선고가 되어 선택이 사라짐) |
| 활·석궁·지팡이·창 | 후열에서도 위력 **온전** |
| 이동 비용 | 그 턴은 공격하지 못함 |

#### 판단력이 눈에 보이는 지점

지금까지 판단력은 추상적인 숫자였는데, 포지션에서 **행동으로 드러납니다.**

측정 결과 (HP 15%인 창병이 물러나는 비율):

| 조건 | 후퇴율 |
|---|---|
| 판단력 10 | 67.7% |
| **판단력 95** | **100%** |
| 판단력 95, 단 **전열에 혼자** | **0%** |
| 판단력 95, 전열에 셋 | 100% |

**베테랑은 물러설 때를 알고, 동시에 물러서면 안 될 때도 압니다.**
전열에 혼자 남았으면 물러나지 않습니다 — 자기가 빠지면 후열이 통째로 노출되니까요.
죽을 걸 알면서 남는 판단이 여기서 나옵니다.

#### 후퇴가 편도가 되지 않게

설계 중 실제로 겪은 함정입니다. 처음엔 "다치면 뒤로"만 넣었더니,
**다친 상태라 다시 앞으로 안 나와서** 근접 캐릭터가 영구히 무력해졌습니다.
회복 수단이 없으면 후퇴는 그냥 천천히 지는 것입니다.

그래서 후퇴 판단에 두 조건을 넣었습니다.
- **회복할 수단(회복약 또는 힐러)이 있을 때만** 물러날 가치가 있음
- 회복해서 여유가 생기면 **다시 앞으로 나감**

### 4.7 회피 · 치명타 · 방어

셋 다 있습니다. 각각 다른 일을 합니다.

| | 담당 스탯 | 하는 일 |
|---|---|---|
| **방어** | 행동 선택 | 받는 피해 0.5배 + 회피율 +10%p. AI가 위험할 때 스스로 선택 |
| **회피** | 민첩 | 완전 무효. **속도 차이**가 좌우 (상한 28%) |
| **치명타** | 기교 + 무기 스타일 | 피해 배증 |

**회피는 절대 회피율이 아니라 속도 차이로 결정됩니다.** 느린 석궁병이 재빠른 검객을
맞히기 어려운 게 자연스럽습니다. 실측: 민첩 60인 대상이 느린 공격자를 상대로는 12.2%,
빠른 공격자를 상대로는 3.7% 회피합니다.

**상한 28%를 둔 이유**는 자동 전투에서 "빗나감"이 연달아 뜨면 답답하기 때문입니다.
회피는 가끔 터지는 반전이어야지 일상이면 안 됩니다.

#### 치명타가 스타일을 갈라놓습니다

확률과 배율을 **반대로** 배치했습니다.

| 스타일 | 치명타율 | 배율 | 성격 |
|---|---|---|---|
| **쌍수** | 10.7% | 1.4배 | 자잘하게 자주 |
| **양손** | 3.1% | 2.1배 | 드물게 한 방 |
| 석궁 | 보통 | 2.0배 | 관통 |

실측: 양손무기 평균 피해가 일반 81 → 치명타 170 (실측 배율 2.10).

#### 왜 넣었나

**민첩이 행동 순서만 바꾸는 얇은 스탯이었습니다.** 6원천 중 하나만 얇으면
육성에서 그 축을 고를 이유가 약하고, 쌍수·활 스타일의 존재 이유도 흐려집니다.

그리고 **자동 전투에는 분산이 필요합니다.** 능력치 차이가 곧 결과면 약자가 강자를
이기는 순간이 없고, 그러면 배속으로 넘겨버리게 됩니다.
"치명타!"가 뜨는 순간이 지켜볼 이유를 만듭니다.

### 4.6 상태 효과 — ⚠️ 폐기됨 → [08](08-design-revision.md) §18

**낡은 내용을 지웠습니다.** 여기에는 *"의도적으로 **7종만** 유지합니다"* 와
강화 2 / 약화 2 / 상태이상 3(중독·둔화·도발됨) 표가 있었습니다.

지금은 **기전 8종 + 이름 26개**입니다. 조합 폭발을 막는 것은 **이름 수를 줄이는 것이
아니라 코드 경로 수를 줄이는 것**이었습니다 — 이름은 데이터 표의 한 줄이고, 새 상태 효과를
추가해도 `switch`가 늘지 않습니다. 중첩 규칙도 이름별 매개변수입니다
(중독은 쌓이고, 화상은 덮어쓰고, 출혈은 행동할 때마다 커집니다).

### 4.4 이 설계가 동시에 푸는 문제들

| 문제 | 해결 |
|---|---|
| "조작이 아예 없으면 심심하다" | 지휘 포인트 개입 |
| "육성의 결과가 안 보인다" | 판단력이 곧 전투 품질. 잘 키우면 눈에 띄게 잘 싸운다 |
| 1인 개발의 전투 개발 비용 | 자동 기반 → 조작 UI·애니메이션 요구 낮음. 배속/스킵 가능 |
| 기술적 도전을 하고 싶다 | **GOAP/Utility AI가 백엔드 기술이 아니라 플레이어가 직접 만지는 시스템이 됨** |
| "파티 구성이 메인" | 캐릭터 조합 + 전술 규칙 조합 = 빌드. 자동 전투가 그 빌드를 검증 |

## 5. 경력 — 달 단위 선택 구조

> ⚠️ **연 단위였습니다.** 지금은 **매달** 정합니다 → [08](08-design-revision.md) §15.
> 아래 표의 "훈련 vs 실전" 대비는 그대로 유효하지만, 단위가 해가 아니라 달입니다.

### 5.1 뼈대

모험가는 **15세에 등록**하고, 그 뒤로 **매달** 무엇을 할지 정합니다.

```
15세         등록
첫 12달      훈련 (강제 — 15세를 바로 전장에 보낼 수는 없다)
그 뒤 매달   훈련 ? 의뢰 ? 휴식 ? 전직 ?
             의뢰를 받으면 그 기간만큼 칸이 잠긴다 (1달 ~ 1년)
 ...         (사망 · 불구 · 은퇴할 때까지)
```

**나이는 12달을 채울 때마다 오릅니다** — 1달 의뢰를 열두 번 한 사람과 1년 의뢰를
한 번 한 사람이 같은 나이가 됩니다.

| | 훈련 | 실전 |
|---|---|---|
| 능력치 성장 | 크다 (수련형이면 더) | 작다 (실전형이면 오히려 더 큼) |
| 판단력 | 조금 오름 | **크게 오름** |
| 수입 | 없음 | 있음 |
| 명성 | 없음 | 있음 |
| **위험** | **없음** | **부상 · 불구 · 사망** |
| 나이 | **먹는다** | **먹는다** |

**양쪽 다 시간을 쓴다는 게 핵심입니다.** 안전한 선택에도 시간이라는 대가가 붙고,
의뢰를 받으면 그 기간 동안 그 사람의 칸이 잠겨 **그 사이에 뜬 의뢰는 못 받습니다.**

### 5.2 왜 이게 도박이 되는가

성장 타입이 숨겨져 있기 때문입니다.

- **대기만성형을 일찍 내보내면** 약한 채로 죽습니다
- **조숙형을 계속 훈련시키면** 전성기를 훈련장에서 낭비하고, 노화가 먼저 옵니다
- **실전형을 훈련장에만 두면** 재능이 안 열립니다
- **수련형을 전장에 굴리면** 성장이 멎습니다

시뮬레이션으로 확인한 실제 격차 (잠재력 동일, 훈련만 시켰을 때 능력치 총합):

| | 19세 | 27세 | 증가 |
|---|---|---|---|
| 조숙형 (개화 17세) | **392** | 435 | +43 |
| 대기만성형 (개화 26세) | 191 | **443** | **+252** |

19세 시점에 조숙형은 대기만성형의 **2배**입니다. "지금 내보내면 벌 수 있는데"라는
유혹이 매년 작동하고, 그게 틀린 판단인지 아닌지는 **확신도가 낮으면 알 수 없습니다.**

### 5.3 실전 사고 — 4단계

생존/사망 둘로만 나누면 너무 거칩니다.

| 결과 | 효과 |
|---|---|
| **무사** | 성장 + 수입 |
| **부상** | 능력치 5~15% 영구 손실. 현역 유지 |
| **불구** | 능력치 30% 손실 + **강제 은퇴**. 살아는 있으므로 멘토는 가능 |
| **사망** | 끝 |

위험은 **능력치 대비 의뢰 난이도**로 결정되고, **판단력이 낮춰줍니다.**
똑똑한 모험가는 물러설 때를 압니다.

> **불구는 "캐릭터를 잃되 완전히 잃지는 않는" 중간 결말입니다.**
> 애착 있는 캐릭터가 한순간에 사라지기만 하면 플레이어는 실전을 아예 기피하게 됩니다.

### 5.4 멘토 — 손실을 자산으로

**살아서 은퇴한(또는 불구가 된) 모험가는 멘토가 됩니다.**

| 멘토가 주는 것 | 근거 |
|---|---|
| 후배 훈련 성장 배율 상승 | 능력치가 높고 실전 경험이 많을수록 잘 가르침 |
| **감정 정확도 상승** | **실전을 오래 살아남은 사람이 재능을 알아봄** |

두 번째가 특히 중요합니다. **실전 리스크를 감수한 것에 대한 장기 보상**이 되고,
"이 아이를 살려서 은퇴시키자"는 동기를 만듭니다.
오래 데리고 있던 캐릭터를 떠나보내는 일이 순수한 상실이 아니게 됩니다.

### 5.5 훈련 연도는 월 단위 — 12턴

**훈련도 실전도 달 단위입니다.** 매달 활동 하나를 골라 훈련하거나 휴식하고,
의뢰를 받으면 그 기간만큼 칸이 잠깁니다.

> ⚠️ 여기에 *"실전 연도는 월 단위로 쪼개지 않고 결과만 봅니다"* 라고 적혀 있었습니다.
> **폐기됐습니다** ([08](08-design-revision.md) §15 · §17). 실전을 결과만 보면
> 1달 의뢰도 1년 의뢰도 만들 수 없고, 달력 잠금이라는 기회비용이 성립하지 않습니다 —
> 그 기회비용이 과잉 전력을 막는 유일한 브레이크입니다.

훈련 활동은 능력치 이름이 아니라 **활동 이름**입니다 (근력·지구력·기술·학술·명상·모의전).
각 활동이 여러 능력치에 가중치로 걸리므로 "민첩만 순수하게"가 불가능합니다.

분기(4턴)가 아니라 월(12턴)인 이유는, **분기는 선택이 너무 굵어서
"내가 이 아이를 키웠다"는 감각이 안 나오기 때문**입니다.

#### 12번 클릭이 되지 않게 하는 장치

| 장치 | 작동 |
|---|---|
| **피로도** | 훈련하면 +17, 휴식하면 −38. 45를 넘으면 성장이 떨어지고, 65를 넘으면 부상 위험 |
| **훈련 부상** | 2~4개월 강제 요양 + 능력치 4% 손실. **그 해가 통째로 날아갈 수 있음** |
| **컨디션** | 매달 변동 (최악 0.70 ~ 절호조 1.30). 피로가 높으면 나빠지는 쪽으로 치우침 |
| **집중과 파급** | 집중한 능력치는 100%, 나머지는 8%. **퍼뜨리면 손해** |

#### ★ 실력이 드러나는 축

배치 시뮬레이션으로 확인한 결과가 하나 있습니다.

> **무모하게 밀어붙이는 것은 이득이 아닙니다** (강행 중앙값 155 vs 신중 159).
> 대신 **컨디션이 좋은 달을 놓치지 않는 것**이 이득입니다 (호기포착 161).

이건 밸런스 실패가 아니라 의도한 결과입니다. 무모함이 보상받으면 육성의 실력 축이
"얼마나 무리하느냐"가 되는데, 그건 판단이 아니라 그냥 손해 감수입니다.
**"좋은 달을 알아보느냐"가 실력이어야 합니다.**

#### 훈련 방침 — 자동 진행

**이건 선택 사항이 아니라 필수 기능입니다.** 길드에 모험가가 여럿이면
12개월 × 인원 × 연차만큼 클릭이 생기고, 전부 손으로 시키면 게임이 노동이 됩니다.

- 애착 있는 캐릭터는 **손으로**, 나머지는 **방침을 맡기고** 넘김
- 기본 방침: 균형 / 전위 / 마법 / 유격
- 변형: 신중(부상 회피) / 강행(시간을 삼) / **호기포착(컨디션 좋으면 밀어붙임)**

그리고 배치 시뮬레이션에도 자동 경로가 반드시 필요합니다 — 사람이 10,000번 클릭할 수는 없습니다.

> **중요한 구현 원칙:** 연 단위 빠른 해석기는 내부적으로 **월 단위 세션을 그대로 돌립니다.**
> 별도 모델을 두었다가 두 경로의 결과가 크게 어긋나는 버그를 실제로 겪었습니다.
> 밸런싱해서 맞춘 값이 실제 플레이와 달라지면 밸런싱 자체가 무의미해집니다.

### 5.7 실전에서 배우는 것 — 겪은 대로 자란다

**훈련은 무엇을 단련할지 고르지만, 실전은 무엇을 겪었는지가 정합니다.**

앞에서 두들겨 맞은 캐릭터와 뒤에서 활만 쏜 캐릭터가 똑같이 자라면
파티 편성과 전술 편성이 육성과 무관해집니다. 그래서 전투 기록이 그대로 성장 데이터가 됩니다.

> ⚠️ 아래 표의 능력치 이름이 **옛 7종(체력/마력/공격/방어/마공/마방/속도)** 이었습니다.
> 지금은 **원천 6종**입니다 — 힘 · 민첩 · 기교 · 활력 · 지능 · 정신 (§3.3).
> 전투 수치(물리 위력·방어·치명타 등)는 원천에서 **파생**됩니다.

| 전투에서 한 것 | 자라는 원천 능력치 |
|---|---|
| 물리 피해를 가함 | 힘 |
| 마법 피해를 가함 | 지능 |
| 회복·강화·도발 | 정신 |
| 물리 피해를 받음 | 활력 |
| 마법 피해를 받음 | 활력, 정신 |
| 위치를 자주 바꿈 | 민첩 |

파생 수치(최대 HP·물리 방어·치명타율 등)는 **겪은 것으로 직접 붙습니다** —
계속 맞다 보면 몸이 단단해지고, 급소를 노리다 보면 손에 익습니다 (`DerivedBonuses`).

**총 성장량은 바뀌지 않고 방향만 바뀝니다.** 어떻게 싸웠느냐가 이득이나 손해가 되면 안 되고,
"어떤 캐릭터가 되느냐"만 갈라져야 하기 때문입니다.
쓰지 않은 능력치도 최소 0.35배는 자랍니다 — 0으로 두면 역할 변경이나 전직이 불가능해집니다.

#### 실측: 잠재력이 완전히 동일한 두 캐릭터, 실전 5년

> ⚠️ **이 실측치는 무효입니다.** 능력치 7종 시절에 잰 것이고, 그 뒤로 능력치 체계·무기·
> 성장 공식이 전부 바뀌었습니다 (`06-balance-log` 무효 항목 · #34 · #35).
> 재측정 전까지 **숫자를 인용하지 마세요.**

살아 있는 것은 **구조**입니다 — 같은 잠재력에서 출발한 두 캐릭터가 **어떻게 싸웠느냐로
완전히 다른 캐릭터가 됩니다.** 전열에서 방패를 들면 맞는 쪽이 자라고, 후열에서
지팡이를 들면 때리는 쪽이 자랍니다.

> **시스템이 여기서 한 바퀴 닫힙니다.**
> 육성 → 무기 → 파티 편성 → 전투 → **다시 육성**.
> 탱커로 굴리면 탱커로 자라고, 후열에 세워두면 맞을 일이 없어 체력이 잘 안 큽니다.

실제 전투를 돌렸다면 그 기록으로, 아직 안 돌렸다면 장비와 위치로 근사합니다.

### 5.8 비전투 역량 — ⚠️ 폐기됨 → [08](08-design-revision.md) §16.8b · §16.8c

**낡은 내용을 지웠습니다.** 여기에는 역량 5종(함정 감지·척후·운반·채집·감정) 표가
있었습니다. 그 개념(`SupportSkill`)은 **에이전트가 상의 없이 만든 것**이고 폐기됐습니다 —
스킬 체계가 이미 그 자리를 담당하므로 축이 중복이었습니다.

목적("전투는 못하지만 데리고 있을 이유")은 **짐꾼**이 대신 이룹니다.

- 짐꾼은 **비전투 직업**입니다. 가방이 **양손을 차지하고 보조무기 칸도 못 쓰므로**
  그 파견 동안 무방비이고, 파티가 지켜야 합니다
- 짐 용량은 근력이 아니라 **가방**에서 나옵니다 — 칸을 내주는 것이 대가입니다.
  포션을 더 들려 보내고 싶어도 들 사람이 없으면 못 보냅니다
- 마물이 짐꾼만 노리지 않습니다 — **표적 최후순위**이고 후열에 섭니다
- 파티 구성 규칙: 짐꾼 최대 1명 · 짐꾼만으로 구성 불가 · 짐꾼 솔로잉 금지

#### ★ 던전 탐험 층을 만들지 않은 이유

함정·척후·운반을 제대로 다루려면 던전 탐험 층, 아이템/무게 인벤토리, 채집·제작,
NPC 경제까지 네 개 시스템이 필요합니다. **최소 6개월이 밀립니다.**
리서치가 1인 개발 실패 원인 1위로 지목한 게 정확히 이 패턴입니다.

대신 **의뢰에 요구 역량을 붙여** 같은 느낌을 냅니다.

```
[폐광 고블린 소탕]   난이도 5 · 전투형
  유리: 함정 감지 ●●●  → 사고 위험 감소
        운반     ●     → 보수 증가

[은광맥 채굴 의뢰]   난이도 3 · 채집형
  유리: 채집 ●●●● / 운반 ●●●
  전투 비중 0.25 — 전투력이 낮은 캐릭터의 자리
```

| 의뢰 성격 | 전투 비중 |
|---|---|
| 전투형 | 1.00 |
| 탐색형 | 0.60 |
| 채집형 | **0.25** |

측정 결과 — 전투력 126인 약골 캐릭터의 난이도 4 의뢰:

| | 보수 | 난이도 7 사망률 |
|---|---|---|
| 전투형 의뢰 | 382 | 4.73% |
| **채집형 의뢰** | **455** | **1.40%** |

**전투가 약한 캐릭터에게 제 몫을 하는 자리가 생깁니다.**
그리고 함정 감지 숙련자가 동행하면 난이도 8 사망률이 2.73% → 1.93%로 떨어집니다.

#### 합산과 최고치

- **함정 감지·척후는 파티 최고 숙련자 기준.** 함정을 찾는 데 다섯 명이 다 필요하진 않습니다
- **운반은 합산.** 짐은 나눠 들 수 있습니다 (숙련자 2인분에서 포화)

> 나중에 실제 던전 탐험을 붙이더라도 **이 데이터 구조는 그대로 씁니다.**
> 지금은 의뢰 해석에 흡수하고, 필요가 확인되면 M4 이후에 얹습니다.

#### 제작은 길드 시설로

대장장이는 별도 시스템이 아니라 **은퇴자가 전직하는 자리**입니다.
이미 만든 멘토 시스템과 같은 구조라, 새 시스템이 늘지 않습니다.

### 5.9 실전을 강제하는 압력 (미구현)

영구 사망이 있으면 플레이어는 **계속 훈련만 시키는 게 최적해**가 됩니다.
그러면 게임이 안 돕니다. 길드 층이 밀어내야 합니다.

- 급여와 시설 유지비 — 훈련만 시키면 재정이 마릅니다
- 연간 의뢰 할당 — 안 받으면 평판이 떨어집니다
- 경쟁 길드가 의뢰를 가져갑니다

**이게 길드 경영 층이 존재해야 하는 이유입니다.** M3에서 구현합니다.

## 6. 길드 층

| 시스템 | 내용 | 우선순위 |
|---|---|---|
| 재정 | 급여, 장비, 시설 유지비 vs 의뢰 보상 | **필수** |
| 의뢰 | 절차적 생성. 난이도·보상·평판 영향 | **필수** |
| 평판 | 받을 수 있는 의뢰의 질을 좌우 | **필수** |
| 시설 | 훈련장, 숙소, 대장간 — 육성 런에 영향 | 중요 |
| 은퇴자 | 교관·상인 등으로 전직해 길드에 기여 | 중요 |
| 경쟁 길드 | AI 길드가 의뢰를 가로챔 | 있으면 좋음 |
| 시즌/연간 목표 | 장기 압박 | 있으면 좋음 |

## 7. 기술적 도전이 게임 디자인과 만나는 지점

목적 3번(기술적 도전)이 게임 재미와 분리되지 않도록 배치했습니다.

| 기술 | 게임 내 역할 |
|---|---|
| **Utility AI** | 전투 중 캐릭터 판단. 판단력 스탯이 파라미터로 개입 |
| **GOAP** | 파티 단위 전술 목표 수립 (돌파 / 방어 / 후퇴) |
| **Behavior Tree** | 수립된 목표의 실행 |
| **절차적 생성** | 모험가 생성, 이벤트, 의뢰, 던전 배치 |
| **시뮬레이션** | 길드 경제, 평판, 경쟁 길드 |
| **결정론적 RNG** | 시드 기반 재현. 밸런스 회귀 테스트와 배치 시뮬레이션의 전제 |

**결정론적 RNG는 선택이 아니라 필수입니다.**
자동 전투 게임의 밸런싱은 "10,000회 시뮬레이션 돌려 승률 분포 보기"로 하는데,
이게 되려면 재현 가능해야 하고, 그러면 AI 에이전트가 밤새 밸런스 통계를 뽑을 수 있습니다.
