# 04. 게임 디자인 문서

작성: 2026-07 · 상태: **초안 (M1 프로토타입으로 검증 예정)**

---

## 1. 컨셉

> **판타지 길드를 운영하며 모험가를 한 명씩 짧게 육성하고,
> 그들로 파티를 짜서 의뢰에 내보내는 게임.**

**한 줄 훅:** 모험가는 스스로 싸운다. 당신이 키운 만큼만.

**장르 태그:** Management, Party-Based RPG, Roguelite, Auto Battler, Character Training

**비교 대상 (플레이어에게 설명할 때):**
"우마무스메의 육성 사이클 + Battle Brothers의 용병단 운영 + 파이널 판타지 12의 감빗"

## 2. 3층 루프 구조

```
┌─ 길드 층 (수십 시간, 세이브 단위) ──────────────────────┐
│  재정 · 평판 · 시설 · 경쟁 길드 · 시즌 진행              │
│                                                          │
│  ┌─ 모험가 층 (30~40분, 반복 단위) ─────────────────┐   │
│  │  영입 → 육성 런 → 은퇴/사망                       │   │
│  │                                                    │   │
│  │  ┌─ 전투 층 (2~5분) ──────────────────────────┐   │   │
│  │  │  파티 편성 → 자동 전투 + 제한된 개입        │   │   │
│  │  └─────────────────────────────────────────────┘   │   │
│  └────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────┘
```

**각 층이 존재하는 이유:**

| 층 | 플레이어에게 주는 것 | 개발 관점의 이유 |
|---|---|---|
| 전투 | 즉각적 피드백, "내 빌드가 통했다" | 자동 기반이라 조작 UI·애니메이션 요구가 낮음 |
| 모험가 | 애착, 반복 가능한 세션, 실험 | **루프 하나만 잘 만들면 콘텐츠로 불릴 수 있음.** 데모 = 육성 런 1회 |
| 길드 | 장기 목표, 러닝타임 | 콘텐츠 재사용으로 플레이 시간 확보. 환불률 방어 |

## 3. 모험가

### 3.1 표현 방식 — 레이어 조합형 초상화

Battle Brothers 방식. 파츠를 레이어로 겹쳐 조합합니다.

```
[배경] → [체형] → [피부/종족] → [얼굴] → [머리] → [수염] → [흉터] → [장비] → [상태 오버레이]
```

**설계 원칙: 아트가 곧 시뮬레이션 상태의 표현이 된다.**

- 부상을 입으면 흉터 레이어가 **영구히** 붙는다
- 나이를 먹으면 머리색이 변한다
- 장비를 바꾸면 초상화에 반영된다
- 사기·부상 상태가 오버레이로 드러난다

파츠 세트 한 벌(예산 10~15만원)로 수천 명의 고유한 모험가를 생성할 수 있고,
**추가 아트 비용 없이 캐릭터가 "변화"합니다.**

### 3.2 애착은 그림이 아니라 기억에서 나온다

이 게임의 핵심 가설입니다. 검증된 선례가 있습니다.

| 게임 | 아트 수준 | 애착의 근원 |
|---|---|---|
| RimWorld | 졸라맨 | 관계 · 트라우마 · 과거사 |
| Dwarf Fortress | ASCII | 생성된 역사 |
| Battle Brothers | 레이어 조합 초상화 | 출신 · 생존한 전투 · 부상 이력 |

따라서 **모든 모험가는 이력(Chronicle)을 누적**합니다.

```
아스카르 (37세, 몰락 귀족 출신)
  · 첫 의뢰에서 동료 미렌을 잃음        → [죄책감] 특성 획득
  · 늑대굴 소탕 3회 성공                → [야수 사냥꾼] 특성
  · 왼팔 부상 (영구)                    → 근력 -15, 흉터 레이어
  · 신입 3명을 훈련시킴                 → [멘토] 특성
  · 은퇴: 42세, 길드 훈련교관으로 전직  → 이후 신입 육성에 보너스
```

은퇴한 모험가가 사라지지 않고 길드에 남는 것이 중요합니다.
**손실이 자산으로 전환되면 애착이 시스템적으로 보상됩니다.**

### 3.3 스탯 설계

**7 능력치**: 체력 · 마력 · 공격 · 방어 · 마공 · 마방 · 속도

능력치마다 잠재력 상한이 따로 굴려지므로, **캐릭터는 자연스럽게 특화됩니다.**
마공과 마력만 높은 아이는 마법사로, 공격과 속도가 높은 아이는 유격수로 쓰게 됩니다.
직업을 고르는 게 아니라 **타고난 것을 발견하는** 구조입니다.

여기에 더해 이 게임의 중심 스탯이 하나 더 있습니다.

| **판단력 (Judgement)** |
|---|
| 전투 중 AI가 얼마나 좋은 선택을 하는지. 그리고 실전에서 얼마나 잘 살아남는지 |

판단력은 **훈련보다 실전에서 훨씬 빠르게 오릅니다.** 죽을 위험을 감수해야 얻어지는
스탯이라는 점이 "언제 내보낼 것인가"라는 질문에 무게를 더합니다.
판단력이 전투에서 어떻게 작동하는지는 4장에서 설명합니다.

### 3.4 성장 타입 — 이 게임의 중심 도박

모든 모험가는 영입 시점에 **숨겨진 성장 곡선**을 갖습니다.

| 요소 | 내용 |
|---|---|
| **개화 시기 (Peak Age)** | 조숙형 17~19세 / 보통 20~23세 / **대기만성형 24~27세** |
| **개화 폭** | 좁으면 짧고 강하게, 넓으면 완만하게 오래 자람 |
| **기질 (Temperament)** | 수련형(훈련에서 잘 배움) / 균형형 / **실전형(실전에서 훨씬 빨리 배움)** |
| **잠재력** | 능력치별 상한. 훈련으로도 넘지 못함 |
| **노화 시작 나이** | 이후 매년 능력치가 깎임 |

개화기에서 멀어도 성장이 완전히 멈추지는 않습니다(최소 22% 배율).
이 하한이 없으면 대기만성형을 데리고 있을 이유가 사라지기 때문입니다.
**개화 시기는 "성장 배율"이지 "성장 가능 여부"가 아닙니다.**

#### ★ 정보 비대칭 — 운을 판단으로 바꾸는 장치

성장 타입은 플레이어에게 **직접 보이지 않습니다.** 하지만 완전히 숨기면 안 됩니다.

> 완전히 숨기면 매년의 선택이 **판단이 아니라 그냥 주사위**가 됩니다.
> 완전히 공개하면 **도박이 사라집니다.**

그래서 **틀릴 수 있는 힌트**를 줍니다.

```
[스카우트 리포트]  확신도: 짐작뿐 (18%)
  · 늦게 피는 편으로 보인다
  · 실전에서 배우는 타입
  · 추정 잠재력: 체58 마71 공49 방52 마공83 마방66 속44
```

**확신도는 이렇게 오릅니다:**
- 함께 보낸 연차 (관찰) — 기여가 점점 둔화됨. 5년쯤이면 웬만큼 알게 됨
- 길드의 감정 시설 투자
- **멘토** — 실전을 오래 살아남은 선배일수록 사람 보는 눈이 좋음

확신도가 낮으면 힌트가 **실제로 틀립니다** (신입·시설 없음 기준 개화 시기 적중률 약 36%).
"확신도 18%"라는 표시 자체가 플레이어에게 의미를 가져야 하기 때문입니다.

결과적으로 **정보 자체가 자원이 되고, 길드 성장의 보상**이 됩니다.

### 3.5 무기 — 육성과 전투를 잇는 다리

무기는 **두 축으로 갈립니다.** 이렇게 나눠야 랜덤 축이 과잉되지 않습니다.

| 축 | 내용 | 랜덤인가 |
|---|---|---|
| **스타일** | 한손+방패 / 쌍수 / 양손 / 활 / 석궁 / 지팡이 / 창 | **적성이 붙음 (랜덤)** |
| **무기종** | 도검 / 둔기 / 도끼 / 자루 | **아니오 — 순수 플레이어 선택** |

무기종에 적성을 붙이지 않는 이유는, 통제 불가능한 변수가 5~6개를 넘으면
플레이어가 결과를 자기 선택 탓으로 돌릴 수 없게 되어 **판단이 체념으로 바뀌기** 때문입니다.

#### 무기는 "얼마나 세냐"가 아니라 "무슨 역할을 할 수 있냐"

능력치가 이미 강함을 담당하므로, 무기가 그걸 반복하면 축이 중복됩니다.
대신 무기는 **파티에서의 역할**을 정합니다.

| 스타일 | 후열 타격 | 후열 배치 | 회복 | 도발 | 광역 | 마법 | 속도 | 위력 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|---|---|
| 한손+방패 | | | | ✓ | | | 0.95 | 0.85 |
| 쌍수 | | | | | ✓ | | 1.20 | 0.95 |
| 양손 | | | | | ✓ | | 0.80 | 1.35 |
| 활 | ✓ | ✓ | | | | | 1.05 | 0.95 |
| 석궁 | ✓ | ✓ | | | | | 0.75 | 1.25 |
| 지팡이 | ✓ | ✓ | ✓ | | ✓ | ✓ | 0.90 | 1.00 |
| 창 | | ✓ | | | | | 1.00 | 1.10 |

**회복은 지팡이만, 도발은 한손+방패만, 후열 타격은 3종만** 가능합니다.
이 희소성이 곧 파티 편성의 구멍을 만듭니다 — "회복이 없다", "후열을 못 때린다".
**말씀하신 "파티 구성이 메인"이 여기서 실현됩니다.**

#### 적성 — 랜덤이되 능력치와 상관관계

적성은 능력치 잠재력에서 파생되되 노이즈가 섞입니다.

| 능력치 성향 | 최고 적성으로 나오는 스타일 (500회) |
|---|---|
| 극단적 마법형 (마공 95, 공 30) | 지팡이 · 활 **2종뿐** |
| 평범하게 고른 능력치 | 쌍수 27% / 한손+방패 21% / 양손 16% / 석궁 13% / 활 12% / 창 8% / 지팡이 4% — **7종 전부** |

**능력치가 극단적이면 무기가 사실상 정해지고, 평범하면 발견의 여지가 큽니다.**
"마공 최고인데 대검 적성" 같은 불량품은 나오지 않으면서, 애매한 아이는 뚜껑을 열어봐야 압니다.

> **안전장치:** 모든 캐릭터는 최소 한 스타일에 B 이상 적성을 보장받습니다.
> 5년 키워서 알아낸 게 "얘는 못 쓴다"면 그건 긴장이 아니라 처벌입니다.

#### 숙련도 — 랜덤이 아니라 이력

적성이 "얼마나 빨리 느는가"라면, 숙련도는 **"실제로 얼마나 익혔는가"**입니다.

- 그 무기를 들고 보낸 햇수만큼 자동으로 쌓입니다 (**훈련 +9 / 실전 +15**)
- 오르는 속도는 적성에 비례 (5년 후 적성 E는 11, S는 61)
- 전투 효율 0.75배(숙련 0) ~ 1.30배(숙련 100)
- **무기를 바꿔도 예전 숙련도는 사라지지 않습니다.** 돌아갈 수는 있되, 새 무기는 처음부터

이래서 "이 아이는 창을 10년 썼다"가 성립하고, **무기 변경에 시간이라는 기회비용**이 붙습니다.

> **월 단위 선택 축을 늘리지 않았습니다.** 숙련도는 장착한 무기로 자동 누적되므로,
> 매달의 선택은 여전히 7능력치 + 휴식이고 무기는 연 단위 결정입니다.

### 3.6 직업 — 숙련도의 이름, 그리고 가치

**직업은 별도의 능력 축이 아닙니다.** 숙련도에서 파생되는 칭호입니다.

> 견습 마법사와 대마법사가 **하는 일은 같습니다.** 다른 것은 **가치**입니다.

| 등급 | 숙련도 | 지팡이 계열 칭호 | 연봉 | 수주 상한 | 평판 기여 |
|---|---|---|---|---|---|
| 견습 | 0~19 | 견습 마법사 | 60 | 난이도 2 | 0 |
| 정식 | 20~44 | 마법사 | 150 | 4 | 2 |
| 상급 | 45~69 | 상급 마법사 | 340 | 6 | 6 |
| 대가 | 70~89 | 대마법사 | 700 | 8 | 15 |
| 전설 | 90~100 | 현자 | 1,000 | 10 | 35 |

스타일마다 칭호 사다리가 따로 있습니다.
한손+방패는 `견습 방패병 → 방패병 → 근위병 → 기사 → 수호기사`,
양손은 `견습 전사 → 전사 → 역전의 전사 → 맹장 → 대전사` 하는 식입니다.

#### 등급이 능력을 주지 않는 이유

등급이 성장 보정이나 스킬을 준다면 **높은 등급 → 빠른 성장 → 더 높은 등급**의
눈덩이가 생겨, 한 번 앞선 캐릭터가 영원히 앞섭니다.

실제 강함 차이는 이미 다른 데서 나옵니다 — **숙련도 자체**(전투 효율 0.75~1.30배)와
**능력치**. 등급은 그걸 부르는 이름이고, 바꾸는 것은 **경제와 자격**입니다.

#### ★ 여기서 길드 경영과 이어집니다

**등급이 오르면 유지비도 오릅니다.** 이게 "훈련만 시키기"를 막는 압력의 출발점입니다.
잘 키운 모험가일수록 놀리는 비용이 비싸지므로 실전으로 밀려납니다.

| 등급 | 연봉 | 최대 수주 보수 | 배율 |
|---|---|---|---|
| 견습 | 60 | 240 | 4.00 |
| 정식 | 150 | 480 | 3.20 |
| 상급 | 340 | 720 | 2.12 |
| 대가 | 700 | 960 | 1.37 |
| **전설** | 1,000 | 1,200 | **1.20** |

**등급이 오를수록 수지가 빠듯해집니다.** 전설급 모험가의 값어치는 의뢰 보수가 아니라
**평판(35)과 난이도 10 수주 자격 그 자체**에서 나옵니다.
그런 사람이 소속되어 있다는 사실이 길드의 자산입니다.

> ⚠️ **급여는 항상 그 등급의 최대 수주 보수보다 낮아야 합니다.**
> 처음에 전설 등급을 1,300으로 잡았다가 최대 보수 1,200을 넘겨 최고 등급이 순수 적자가 됐습니다.
> 테스트로 고정해 두었습니다.

#### 전직

**무기를 바꾸면 등급이 떨어집니다.** 대마법사가 대검을 잡으면 견습 전사입니다.
연봉도 1,300에서 60으로 떨어집니다. 그게 전직의 대가이고, 그래서 결심이 필요합니다.

다만 **예전 숙련도는 사라지지 않으므로 돌아갈 수 있고**,
**최고 도달 등급(PeakRank)은 기록으로 남습니다.**
전직해서 견습으로 돌아가도 "한때 대마법사였던" 사실은 지워지지 않습니다.

그리고 전직의 현실성은 **적성**이 정합니다. 같은 5년을 들여도
적성 E면 숙련 11(견습), S면 61(상급)입니다.
**"이 아이는 전직해야 한다"를 알아보려면 감정에 투자해야 하고,
그래서 감정 시스템에 투자할 이유가 생깁니다.**

## 4. 전투 — 감빗 + 판단력 모델

> **전투는 자동으로 진행된다. 다만 캐릭터가 얼마나 똑똑하게 싸우는지는
> 육성으로 얻은 판단력과 플레이어가 편성한 전술 규칙이 결정한다.**

### 4.1 전술 규칙 (Tactic)

FF12 감빗과 유사한 조건-행동 규칙입니다. 위에서부터 순서대로 평가합니다.

```
1. [아군 HP < 30%]          → 회복약 사용
2. [적이 시전 중]            → 차단
3. [적 후위가 노출됨]        → 돌격
4. (기본)                    → 가장 가까운 적 공격
```

**규칙 슬롯은 육성으로 늘어나고, 규칙 자체도 육성으로 배웁니다.**
신입은 슬롯 2개에 기본 규칙만 갖고, 베테랑은 슬롯 6개에 정교한 규칙을 갖습니다.

### 4.2 판단력 = AI 품질

여기가 이 설계의 핵심입니다. **판단력 스탯이 AI의 실행 품질을 좌우합니다.**

| 판단력 | 전투 중 행동 |
|---|---|
| 낮음 | 규칙을 자주 무시한다. 위험할 때 후퇴하지 않고, 회복약을 아끼다 죽는다. 타겟 선택이 나쁘다 |
| 보통 | 규칙대로 움직인다 |
| 높음 | 규칙에 없는 상황도 스스로 잘 판단한다 (Utility AI의 가중치가 정확해짐) |

구현상으로는 **Utility AI의 점수 계산에 판단력이 개입**합니다.
판단력이 낮으면 점수에 노이즈가 끼거나 근시안적 평가(다음 1턴만 봄)를 하고,
높으면 정확하고 멀리 봅니다.

### 4.3 플레이어의 개입

전투당 제한된 **지휘 포인트(Command Point)** 를 씁니다.

| 개입 | 비용 |
|---|---|
| 특정 캐릭터에게 즉시 행동 지시 | 1 |
| 집중 타겟 지정 (파티 전체) | 1 |
| 후퇴 / 대형 변경 | 2 |
| 규칙 일시 무시하고 직접 조작 (1턴) | 2 |

**개입권이 제한적이라 "언제 쓸까"가 매 전투의 판단 재미가 됩니다.**
그리고 잘 키운 파티일수록 개입할 일이 없어지므로, **육성의 보상이 즉각적으로 체감됩니다.**

### 4.5 포지션 — 고정된 대형이 아니라 매 순간의 선택

**전열/후열은 배치가 아니라 행동입니다.** 전투 중 언제든 이동할 수 있고, 그 판단이 곧 판단력입니다.

| 규칙 | 내용 |
|---|---|
| 근접 무기의 사거리 | 적 **전열까지만** 닿음 |
| **전열이 비면** | 후열이 그대로 노출됨 → 전열 유지 자체가 방어 행위 |
| 후열에 있으면 | 받는 피해 **0.75배** |
| 근접 무기가 후열에서 | 위력 **0.45배** (0이 아닌 이유: 완전 무력화되면 후퇴가 사망 선고가 되어 선택이 사라짐) |
| 활·석궁·지팡이·창 | 후열에서도 위력 **온전** |
| 이동 비용 | 그 턴은 공격하지 못함 |

#### 판단력이 눈에 보이는 지점

지금까지 판단력은 추상적인 숫자였는데, 포지션에서 **행동으로 드러납니다.**

측정 결과 (HP 15%인 창병이 물러나는 비율):

| 조건 | 후퇴율 |
|---|---|
| 판단력 10 | 67.7% |
| **판단력 95** | **100%** |
| 판단력 95, 단 **전열에 혼자** | **0%** |
| 판단력 95, 전열에 셋 | 100% |

**베테랑은 물러설 때를 알고, 동시에 물러서면 안 될 때도 압니다.**
전열에 혼자 남았으면 물러나지 않습니다 — 자기가 빠지면 후열이 통째로 노출되니까요.
죽을 걸 알면서 남는 판단이 여기서 나옵니다.

#### 후퇴가 편도가 되지 않게

설계 중 실제로 겪은 함정입니다. 처음엔 "다치면 뒤로"만 넣었더니,
**다친 상태라 다시 앞으로 안 나와서** 근접 캐릭터가 영구히 무력해졌습니다.
회복 수단이 없으면 후퇴는 그냥 천천히 지는 것입니다.

그래서 후퇴 판단에 두 조건을 넣었습니다.
- **회복할 수단(회복약 또는 힐러)이 있을 때만** 물러날 가치가 있음
- 회복해서 여유가 생기면 **다시 앞으로 나감**

### 4.6 상태 효과

의도적으로 **7종만** 유지합니다. 상태이상을 20종 만들면 조합 폭발로 밸런싱이 불가능해집니다.

| 강화 | 약화 | 상태이상 |
|---|---|---|
| 공격 강화 · 방어 강화 | 공격 약화 · 방어 약화 | 중독 · 둔화 · 도발됨 |

**같은 종류는 중첩되지 않고 덮어씁니다.** 이것도 조합 폭발 방지입니다.

### 4.4 이 설계가 동시에 푸는 문제들

| 문제 | 해결 |
|---|---|
| "조작이 아예 없으면 심심하다" | 지휘 포인트 개입 |
| "육성의 결과가 안 보인다" | 판단력이 곧 전투 품질. 잘 키우면 눈에 띄게 잘 싸운다 |
| 1인 개발의 전투 개발 비용 | 자동 기반 → 조작 UI·애니메이션 요구 낮음. 배속/스킵 가능 |
| 기술적 도전을 하고 싶다 | **GOAP/Utility AI가 백엔드 기술이 아니라 플레이어가 직접 만지는 시스템이 됨** |
| "파티 구성이 메인" | 캐릭터 조합 + 전술 규칙 조합 = 빌드. 자동 전투가 그 빌드를 검증 |

## 5. 경력 — 연 단위 선택 구조

### 5.1 뼈대

모험가는 **15세에 등록**하고, 그 뒤로 매년 한 번씩 무거운 선택을 합니다.

```
15세  등록
16세  훈련 (강제 — 15세를 바로 전장에 보낼 수는 없다)
17세  훈련 ? 실전 ?
18세  훈련 ? 실전 ?
19세  훈련 ? 실전 ?
 ...  (사망 · 불구 · 은퇴할 때까지)
```

| | 훈련 | 실전 |
|---|---|---|
| 능력치 성장 | 크다 (수련형이면 더) | 작다 (실전형이면 오히려 더 큼) |
| 판단력 | 조금 오름 | **크게 오름** |
| 수입 | 없음 | 있음 |
| 명성 | 없음 | 있음 |
| **위험** | **없음** | **부상 · 불구 · 사망** |
| 나이 | **먹는다** | **먹는다** |

**양쪽 다 1년을 쓴다는 게 핵심입니다.** 안전한 선택에도 시간이라는 대가가 붙습니다.

### 5.2 왜 이게 도박이 되는가

성장 타입이 숨겨져 있기 때문입니다.

- **대기만성형을 일찍 내보내면** 약한 채로 죽습니다
- **조숙형을 계속 훈련시키면** 전성기를 훈련장에서 낭비하고, 노화가 먼저 옵니다
- **실전형을 훈련장에만 두면** 재능이 안 열립니다
- **수련형을 전장에 굴리면** 성장이 멎습니다

시뮬레이션으로 확인한 실제 격차 (잠재력 동일, 훈련만 시켰을 때 능력치 총합):

| | 19세 | 27세 | 증가 |
|---|---|---|---|
| 조숙형 (개화 17세) | **392** | 435 | +43 |
| 대기만성형 (개화 26세) | 191 | **443** | **+252** |

19세 시점에 조숙형은 대기만성형의 **2배**입니다. "지금 내보내면 벌 수 있는데"라는
유혹이 매년 작동하고, 그게 틀린 판단인지 아닌지는 **확신도가 낮으면 알 수 없습니다.**

### 5.3 실전 사고 — 4단계

생존/사망 둘로만 나누면 너무 거칩니다.

| 결과 | 효과 |
|---|---|
| **무사** | 성장 + 수입 |
| **부상** | 능력치 5~15% 영구 손실. 현역 유지 |
| **불구** | 능력치 30% 손실 + **강제 은퇴**. 살아는 있으므로 멘토는 가능 |
| **사망** | 끝 |

위험은 **능력치 대비 의뢰 난이도**로 결정되고, **판단력이 낮춰줍니다.**
똑똑한 모험가는 물러설 때를 압니다.

> **불구는 "캐릭터를 잃되 완전히 잃지는 않는" 중간 결말입니다.**
> 애착 있는 캐릭터가 한순간에 사라지기만 하면 플레이어는 실전을 아예 기피하게 됩니다.

### 5.4 멘토 — 손실을 자산으로

**살아서 은퇴한(또는 불구가 된) 모험가는 멘토가 됩니다.**

| 멘토가 주는 것 | 근거 |
|---|---|
| 후배 훈련 성장 배율 상승 | 능력치가 높고 실전 경험이 많을수록 잘 가르침 |
| **감정 정확도 상승** | **실전을 오래 살아남은 사람이 재능을 알아봄** |

두 번째가 특히 중요합니다. **실전 리스크를 감수한 것에 대한 장기 보상**이 되고,
"이 아이를 살려서 은퇴시키자"는 동기를 만듭니다.
오래 데리고 있던 캐릭터를 떠나보내는 일이 순수한 상실이 아니게 됩니다.

### 5.5 훈련 연도는 월 단위 — 12턴

**훈련하는 해는 12개월로 쪼개집니다.** 매달 7개 능력치 중 하나를 골라 훈련하거나 휴식합니다.
실전 연도는 월 단위로 쪼개지 않고 결과만 봅니다 — 생각할 거리가 있는 쪽에만 시간을 씁니다.

분기(4턴)가 아니라 월(12턴)인 이유는, **분기는 선택이 너무 굵어서
"내가 이 아이를 키웠다"는 감각이 안 나오기 때문**입니다.

#### 12번 클릭이 되지 않게 하는 장치

| 장치 | 작동 |
|---|---|
| **피로도** | 훈련하면 +17, 휴식하면 −38. 45를 넘으면 성장이 떨어지고, 65를 넘으면 부상 위험 |
| **훈련 부상** | 2~4개월 강제 요양 + 능력치 4% 손실. **그 해가 통째로 날아갈 수 있음** |
| **컨디션** | 매달 변동 (최악 0.70 ~ 절호조 1.30). 피로가 높으면 나빠지는 쪽으로 치우침 |
| **집중과 파급** | 집중한 능력치는 100%, 나머지는 8%. **퍼뜨리면 손해** |

#### ★ 실력이 드러나는 축

배치 시뮬레이션으로 확인한 결과가 하나 있습니다.

> **무모하게 밀어붙이는 것은 이득이 아닙니다** (강행 중앙값 155 vs 신중 159).
> 대신 **컨디션이 좋은 달을 놓치지 않는 것**이 이득입니다 (호기포착 161).

이건 밸런스 실패가 아니라 의도한 결과입니다. 무모함이 보상받으면 육성의 실력 축이
"얼마나 무리하느냐"가 되는데, 그건 판단이 아니라 그냥 손해 감수입니다.
**"좋은 달을 알아보느냐"가 실력이어야 합니다.**

#### 훈련 방침 — 자동 진행

**이건 선택 사항이 아니라 필수 기능입니다.** 길드에 모험가가 여럿이면
12개월 × 인원 × 연차만큼 클릭이 생기고, 전부 손으로 시키면 게임이 노동이 됩니다.

- 애착 있는 캐릭터는 **손으로**, 나머지는 **방침을 맡기고** 넘김
- 기본 방침: 균형 / 전위 / 마법 / 유격
- 변형: 신중(부상 회피) / 강행(시간을 삼) / **호기포착(컨디션 좋으면 밀어붙임)**

그리고 배치 시뮬레이션에도 자동 경로가 반드시 필요합니다 — 사람이 10,000번 클릭할 수는 없습니다.

> **중요한 구현 원칙:** 연 단위 빠른 해석기는 내부적으로 **월 단위 세션을 그대로 돌립니다.**
> 별도 모델을 두었다가 두 경로의 결과가 크게 어긋나는 버그를 실제로 겪었습니다.
> 밸런싱해서 맞춘 값이 실제 플레이와 달라지면 밸런싱 자체가 무의미해집니다.

### 5.7 실전에서 배우는 것 — 겪은 대로 자란다

**훈련은 무엇을 단련할지 고르지만, 실전은 무엇을 겪었는지가 정합니다.**

앞에서 두들겨 맞은 캐릭터와 뒤에서 활만 쏜 캐릭터가 똑같이 자라면
파티 편성과 전술 편성이 육성과 무관해집니다. 그래서 전투 기록이 그대로 성장 데이터가 됩니다.

| 전투에서 한 것 | 자라는 능력치 |
|---|---|
| 물리 피해를 가함 | 공격 |
| 마법 피해를 가함 | 마공, 마력 |
| 회복·강화·도발 | 마력 |
| 물리 피해를 받음 | 체력, 방어 |
| 마법 피해를 받음 | 체력, 마방 |
| 위치를 자주 바꿈 | 속도 |

**총 성장량은 바뀌지 않고 방향만 바뀝니다.** 어떻게 싸웠느냐가 이득이나 손해가 되면 안 되고,
"어떤 캐릭터가 되느냐"만 갈라져야 하기 때문입니다.
쓰지 않은 능력치도 최소 0.35배는 자랍니다 — 0으로 두면 역할 변경이나 전직이 불가능해집니다.

#### 실측: 잠재력이 완전히 동일한 두 캐릭터, 실전 5년

| | 체력 | 마력 | 공격 | 방어 | 마공 | 마방 | 속도 |
|---|---|---|---|---|---|---|---|
| 한손+방패 (전열) | **90** | 69 | **82** | **89** | 52 | 51 | 55 |
| 지팡이 (후열) | 54 | **92** | 56 | 55 | **90** | **83** | 53 |

같은 잠재력(전 능력치 90)에서 출발했는데 **완전히 다른 캐릭터가 됩니다.**
차이를 만든 건 오직 "어떻게 싸웠는가"입니다.

> **시스템이 여기서 한 바퀴 닫힙니다.**
> 육성 → 무기 → 파티 편성 → 전투 → **다시 육성**.
> 탱커로 굴리면 탱커로 자라고, 후열에 세워두면 맞을 일이 없어 체력이 잘 안 큽니다.

실제 전투를 돌렸다면 그 기록으로, 아직 안 돌렸다면 장비와 위치로 근사합니다.

### 5.6 실전을 강제하는 압력 (미구현)

영구 사망이 있으면 플레이어는 **계속 훈련만 시키는 게 최적해**가 됩니다.
그러면 게임이 안 돕니다. 길드 층이 밀어내야 합니다.

- 급여와 시설 유지비 — 훈련만 시키면 재정이 마릅니다
- 연간 의뢰 할당 — 안 받으면 평판이 떨어집니다
- 경쟁 길드가 의뢰를 가져갑니다

**이게 길드 경영 층이 존재해야 하는 이유입니다.** M3에서 구현합니다.

## 6. 길드 층

| 시스템 | 내용 | 우선순위 |
|---|---|---|
| 재정 | 급여, 장비, 시설 유지비 vs 의뢰 보상 | **필수** |
| 의뢰 | 절차적 생성. 난이도·보상·평판 영향 | **필수** |
| 평판 | 받을 수 있는 의뢰의 질을 좌우 | **필수** |
| 시설 | 훈련장, 숙소, 대장간 — 육성 런에 영향 | 중요 |
| 은퇴자 | 교관·상인 등으로 전직해 길드에 기여 | 중요 |
| 경쟁 길드 | AI 길드가 의뢰를 가로챔 | 있으면 좋음 |
| 시즌/연간 목표 | 장기 압박 | 있으면 좋음 |

## 7. 기술적 도전이 게임 디자인과 만나는 지점

목적 3번(기술적 도전)이 게임 재미와 분리되지 않도록 배치했습니다.

| 기술 | 게임 내 역할 |
|---|---|
| **Utility AI** | 전투 중 캐릭터 판단. 판단력 스탯이 파라미터로 개입 |
| **GOAP** | 파티 단위 전술 목표 수립 (돌파 / 방어 / 후퇴) |
| **Behavior Tree** | 수립된 목표의 실행 |
| **절차적 생성** | 모험가 생성, 이벤트, 의뢰, 던전 배치 |
| **시뮬레이션** | 길드 경제, 평판, 경쟁 길드 |
| **결정론적 RNG** | 시드 기반 재현. 밸런스 회귀 테스트와 배치 시뮬레이션의 전제 |

**결정론적 RNG는 선택이 아니라 필수입니다.**
자동 전투 게임의 밸런싱은 "10,000회 시뮬레이션 돌려 승률 분포 보기"로 하는데,
이게 되려면 재현 가능해야 하고, 그러면 AI 에이전트가 밤새 밸런스 통계를 뽑을 수 있습니다.
