# 11. 리서치 — 아트 · 사운드 · 스토어 자산

조사: 2026-07 · 결론은 [ADR 0002](adr/0002-no-genai-in-shipped-content.md), [ADR 0003](adr/0003-portrait-layering.md)

전제: **프로그래머 1인, 아트 역량 없음, 예산 30~50만원.**

---

## 1. 아트 없이 통하는 비주얼 전략

### 검증된 사례

| 게임 | 개발 | 비주얼 접근 | 성과 |
|---|---|---|---|
| **Balatro** | LocalThunk **1인** (IT 직군 출신) | 카드 UI + 셰이더/이펙트 "juice". 캐릭터 아트 거의 없음 | **출시 첫 시간 내 손익분기**, 3일 25만 장, 2025년 1월 **500만 장**, TGA 2관왕 |
| **Vampire Survivors** | Luca Galante **1인** | **구매 에셋 픽셀아트**. Phaser HTML5 기본 에셋에서 시작 | 2~3개월 내 100만 장 초과. **"거의 돈을 쓰지 않음"** |
| **Thomas Was Alone** | Mike Bithell | 사각형 + 색 + 내레이션 | 미니멀리즘 상업 성공의 정전 |
| **Battle Brothers** | 소규모 | **레이어 조합형 정면 초상화** | 장수 상업작. 이 프로젝트의 직접 참고 대상 |

**Balatro와 Vampire Survivors는 결정적 증거입니다.** 둘 다 프로그래머 1인, 아트 역량 없음, 최상위 성과.
공통점은 아트가 아니라 **"한 번 더" 루프의 강도**와 **화면 피드백(juice)의 밀도**입니다.

### 난이도 순서 (프로그래머 혼자 감당 가능한 순)

1. **기하학/추상** — 최저. 코드로 100% 생성. 리스크: "성의 없음"으로 읽힐 수 있어 **팔레트와 모션이 전부**
2. **실루엣/모노크롬** — 낮음. 형태만 맞으면 되고 텍스처·음영 불필요
3. **플랫/벡터** — 낮음~중간. 툴로 정확한 형태 제작 가능
4. **로우폴리 3D** — 중간. **에셋 구매와 궁합이 가장 좋음.** 픽셀아트 대비 매출 중앙값과 수요가 유의미하게 높음
5. **픽셀아트** — 진입장벽은 낮으나 **숙련 상한이 매우 높음.** Steam "Pixel Graphics" 태그에 수만 종이 몰려
   있어 **어중간하면 즉시 묻힘**

> ⚠️ **"쉬워 보여서 픽셀아트"는 가장 흔하면서 가장 위험한 선택입니다.**

### 코드로 만드는 비주얼 (프로그래머의 최대 무기)

- **노멀맵 + 실시간 조명**: 2D 스프라이트가 광원에 반응 → 저렴한 아트를 즉시 "고급"으로
- **단일 쿼드 + 셰이더**: 스크롤링/알파 이로전만으로 이펙트 생성 — 아트 에셋 0개
- **절차적 생성**: 콘텐츠 양 문제를 코드로 해결 (RimWorld, FTL)

### ★ 진짜 분기점은 "게임 내 아트"가 아니라 "캡슐 이미지"

Chris Zukowski의 분석: **위시리스트 5,000 미만 + 비전문적 캡슐 아트 + 느린 리뷰 누적**의 조합은
출시 시점부터 알고리즘에 억제됩니다. 그는 캡슐에 대해
**"전문 아티스트가 만들어야 한다 — 광고에 돈 쓰기 전에 여기부터"**라고 명시합니다.

> Balatro와 Vampire Survivors는 게임 내 아트가 약했지만 **스토어 첫인상은 약하지 않았습니다.**
> "아트 때문에 묻힌 게임"의 실체는 대부분 **"캡슐에서 클릭을 못 받아서"**입니다.

## 2. 에셋과 외주 비용

### 에셋 가격대 (2026년)

| 소스 | 가격 | 라이선스 |
|---|---|---|
| **Kenney All-in-1** | **$19.95** (60,000개+ 에셋) / 개별 팩 $9.95 | **CC0** — 무제한 상업 이용, 저작자 표시 불필요 |
| **Synty POLYGON** | 팩당 $49.99~$149.99 / **구독 $30/월**로 130개+ 팩 | 상업 이용 가능 |
| Unity Asset Store | 카탈로그 80,000개+ | 상업 이용 가능 |
| Godot Asset Library | 약 3,000개 (무료 중심) | — |
| itch.io 팩 | $6~ | 팩별 상이 |

### 에셋 플립 낙인의 경계선

**낙인이 안 찍히는 조건:** ① 일관성(단일 공급원 또는 조명·셰이더로 통합) ②가공 ③**게임플레이의 실재** ④투명성
**찍히는 조건:** 무가공 배치 + 출처 혼합 + 게임 실체 부재 + 은폐

> **Vampire Survivors는 구매 에셋으로 만들어졌고 에셋 플립으로 불리지 않았습니다.
> 차이는 게임이 실재했다는 것뿐입니다.**

### 프리랜서 외주 단가 (2025~2026)

- 지역별 시급: 동남아 $20~45 / 인도 $25~55 / 동유럽 $30~60 / 북미·서유럽 $80~150
- 픽셀아티스트 시급 $12~20. 다중 상태 풀 애니메이션 캐릭터 1종에 **20~40시간**
  → **완전 커스텀 캐릭터 1종 = $240~800**
- 타일셋: $20~60/세트

**Steam 캡슐/키아트 (가장 중요)**

| 등급 | 비용 |
|---|---|
| Fiverr 풀세트 최저 | $130 |
| **인디 일반 구간 (완전 커스텀)** | **$300~600** |
| 전문가 | $500~3,000+ |

### 현실적 예산 하한선

| 티어 | 아트 총액 | 구성 |
|---|---|---|
| **최소 생존선** | **$500~800** | 캡슐 외주 $300~600 + CC0/저가 에셋 + 나머지 자체 |
| 권장 하한선 | $1,500~3,000 | 캡슐 $600~1,000 + UI 외주 + 에셋 팩 |
| 안전 구간 | $5,000~8,000 | + 커스텀 캐릭터 소수 + 전문 트레일러 |

**이 프로젝트(30~50만원 ≈ $220~360)는 "최소 생존선" 아래입니다.**
따라서 캡슐에 집중하고, 게임 내 비주얼은 레이어 조합 + 코드로 해결해야 합니다.

## 3. 생성형 AI 아트 — 2026년 리스크

상세는 [ADR 0002](adr/0002-no-genai-in-shipped-content.md). 요약:

- Steam 게임 **53,597종 전수 조사**: AI 공개 시 **리뷰 수 약 53% 감소**
- 스튜디오 **매출 40~60% 감소** 추정
- **2026년 1월 개정으로 마케팅 자료와 스토어 페이지도 공개 의무 대상**
- 미국 저작권청 2025년 1월 보고서: **인간 창작 기여 없는 AI 생성물은 저작권 보호 불가**
- **The Alters**: 미공개 사용 발각. 실패 원인은 "AI를 썼다"가 아니라 **"지우지 않았고 공개하지 않았다"**
- **Shrine's Legacy**: **실제 인간 아티스트만 썼는데** AI 의혹으로 리뷰 폭탄

> ⚠️ Shrine's Legacy 사례는 미니멀/조합형 전략에 직접 영향을 줍니다.
> 지나치게 매끈하거나 출처가 불분명한 비주얼은 AI로 오인받을 수 있습니다.
> **devlog · 타임랩스 · 작업 과정 공개를 선제적 방어책으로 준비하세요.**

**안전 구역** (Steam 공개 면제): 코드 어시스턴트, 내부 컨셉 탐색, 배포하지 않는 프로토타입 플레이스홀더.
단 플레이스홀더는 [ADR 0002](adr/0002-no-genai-in-shipped-content.md)의 기계적 제거 절차를 따를 것.

### 음악

| 옵션 | 가격 |

> 계약 전 약관의 "video game / interactive media / synchronization in a product" 조항을

### 사운드 부재의 영향

**아트가 약할수록 사운드가 "완성도"에 대한 인식을 대신 지탱합니다.**
Balatro의 카드 뒤집기·칩 소리처럼, 단순한 비주얼 + 강한 오디오 피드백은 극도로 높은 가성비를 냅니다.

## 5. 스토어 페이지 자산

### 캡슐 이미지 — 단일 최고 레버리지

- **트래픽 증가가 전혀 없어도, 캡슐 교체만으로 위시리스트 30~70% 증가**
- **CTR 벤치마크: 0.5% 미만이면 묻히고, 1~2%가 안전 구간**
- 캡슐은 다른 모든 요소의 **게이트** — 클릭이 없으면 트레일러도 설명도 노출되지 않음

> **게임 내 아트를 100시간 개선하는 것보다 캡슐 1장의 ROI가 높습니다.**

### 트레일러

| 등급 | 비용 |
|---|---|
| 기본 2D | $3,000~ |
| 전문 게임플레이 트레일러 | $5,000~12,000 |
| 시네마틱 3D | $20,000+ |

**트레일러는 "게임에 이미 존재하는 것을 촬영·편집"하는 작업이라
아트 능력 없이도 자체 제작 가능한 몇 안 되는 마케팅 자산입니다.**
원칙: 첫 3초에 핵심 훅, 로고/인터페이스 화면 최소화, 게임플레이 밀도 최대화.

> **예산이 $2,000 미만이면 트레일러는 자체 제작하고 그 돈을 캡슐에 쓰는 것이 데이터상 합리적입니다.**

## 6. 이 프로젝트의 결론

1. **게임 내 비주얼**: 레이어 조합형 초상화 + UI + 셰이더/모션. [ADR 0003](adr/0003-portrait-layering.md)
2. **예산 집중**: 캡슐 이미지 25~35만원 + 초상화 파츠 세트 10~15만원
3. **효과음**: Sonniss GDC 번들 (0원)
4. **트레일러**: 자체 제작 (0원)
5. **생성형 AI**: 출시물에 일절 사용하지 않음. devlog로 제작 과정을 선제 공개해 오인 방어
6. **에셋**: 쓴다면 **단일 공급원**에서만. 혼합은 에셋 플립 낙인의 1차 트리거
